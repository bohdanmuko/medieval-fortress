# Середньовічна фортеця на пагорбі — Three.js

Інтерактивна 3D-сцена: замок на пагорбі з ровом і підйомним мостом, табір облоги з требушетом, руйнівна фізика, динамічна зміна часу доби, власні GLSL-шейдери.

**Стек:** Three.js 0.170 · Vite 6 · cannon-es 0.20 (фізика) · lil-gui 0.20

## Запуск

```bash
npm install
npm run dev        # розробка
npm run build      # продакшн-збірка → dist/
npm run preview    # перегляд збірки
```

Деплой: Vercel (Framework Preset — Vite, `vercel.json` уже є) або GitHub Pages / Netlify (`dist/`, у `vite.config.js` `base: './'`).
**У репозиторій не комітити `node_modules` і `dist`** (є `.gitignore`).

Параметр `?q=low|medium|high|ultra` у URL задає якість рендера; без нього діє адаптивна якість (знижується, якщо fps < 24).

## Структура

| Файл | Що робить |
|---|---|
| `src/world.js` | Спільна «географія»: висота рельєфу `terrainHeight`, розміри замку, рів, дорога. Без Three.js — її використовують і візуал, і фізика |
| `src/geo.js` | Допоміжна геометрія: UV у метрах, заокруглений прямокутник, розтягування циліндра між точками |
| `src/materials.js` | Усі текстури та матеріали (PBR-набори, дерево/прапори/дим на canvas, двері з displacement) |
| `src/shaders.js` | Власні шейдери (див. нижче) |
| `src/terrain.js` | Меш рельєфу (PlaneGeometry зі зміщеними вершинами) і вода рову |
| `src/castle.js` | Замок з примітивів + 2 ExtrudeGeometry, колайдери, смолоскипи |
| `src/camp.js` | Требушет (анімація + балістика), намети, багаття, частокіл, віз |
| `src/models.js` | Імпорт glTF: воїн (скелетна анімація), кінь (morph targets) |
| `src/vegetation.js` | Дерева, каміння, кущі (InstancedMesh) |
| `src/physics.js` | cannon-es: heightfield, колайдери, цегляні мури, снаряди, кінематичний міст |
| `src/effects.js` | Дим/пил (спрайти), птахи, зорі |
| `src/main.js` | Рендерер, пост-обробка, небо й час доби, камера, UI, головний цикл |

## Відповідь на вимоги завдання

**Примітиви.** Box, Cylinder, Cone, Sphere, Lathe, Torus, Circle, Plane, Dodecahedron/Icosahedron — стіни, вежі, дахи, міст, ятки, колодязь, бочки, намети, дерева. Дві `ExtrudeGeometry`: арка брами (контур з отвором-аркою) і двосхилий дах зали/колодязя.

**Складні моделі.** `Soldier.glb` (SkinnedMesh, Mixamo-кістки, клипи Idle/Walk/Run; ~12 клонів через `SkeletonUtils.clone`, кожен зі своїм `AnimationMixer`) і `Horse.glb` (morph targets, галоп). Файли з прикладів three.js r170.

**Матеріали.** PBR-набори (колір + ARM + нормаль) для цегли, вапняку, черепиці, каменю, листя; процедурне дерево (canvas, колір + bump); гербові прапори (canvas); двері зі всіма картами курсу (displacement, alpha, AO, metalness, roughness, normal); металеві (залізо, бронза); скло вікон, що світиться вночі (emissive).

**Освітлення.** Одне спрямоване світло (вдень — сонце, вночі — місяць), `HemisphereLight`, IBL з карти довкілля, згенерованої з неба (`PMREMGenerator`), `PointLight` від смолоскипів/жаровень/багаття з мерехтінням.

**Тіні.** `PCFSoftShadowMap`, карта до 4096², тіні від усіх об'єктів (включно з воїнами, кіньми, деревами через InstancedMesh), `bias`/`normalBias` підібрані проти «акне».

**Анімація.** Скелетна (воїни), morph (кінь), механічна (требушет: плече, противага, праща, лебідка; міст і решітка), прапори й дерева (шейдери), вода, хмари, вогонь, птахи, цикл доби.

**Фізика.** cannon-es: `Heightfield` рельєфу (будується з тієї ж `terrainHeight`), статичні колайдери замку, ~230 динамічних тіл (цегла, бочки, ящики, тюки), снаряди 260 кг, кінематичне тіло моста, сон/пробудження тіл. Требушет рахує початкову швидкість зі формули `v² = g·d² / (2cos²θ(d·tgθ − Δy))`.

**Рендер.** `EffectComposer` з MSAA (HalfFloat target) → `GTAOPass` (амбієнт-оклюзія) → `UnrealBloomPass` → `OutputPass` (ACES tone mapping + sRGB) → власний `ShaderPass`; тіні 4096²; PMREM IBL; анізотропна фільтрація; `FogExp2`; пресети якості + адаптивне зниження.

**Шейдер(и).** У `src/shaders.js`:
1. рельєф — змішування трава/скеля/дорога/мул за нахилом, висотою й маскою дороги (`onBeforeCompile` над `MeshStandardMaterial`);
2. прапор — хвилі у вершинному шейдері з аналітичною нормаллю;
3. гойдання крон на вітрі (з підтримкою InstancedMesh);
4. вогонь — білборд + fbm-шум, адитивне змішування, HDR для bloom (`ShaderMaterial`);
5. вода рову — дві рухомі нормал-мапи, Френель, відблиск сонця, туман;
6. хмари на півсфері (fbm) + серпанок на горизонті;
7. фінальна обробка кадру: віньєтка, зерно, контраст, насиченість.
